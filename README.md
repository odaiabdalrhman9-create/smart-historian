# المؤرخ الذكي — MVP

نسخة أولية كاملة لواجهة Web App باللغة العربية RTL لتدريب التفكير التاريخي السببي.

## التشغيل

1. ثبّت Node.js 20 أو أحدث.
2. داخل المجلد:
   npm install
   npm run dev
3. افتح:
   http://localhost:3000

## ما الموجود؟
- الصفحة الرئيسية والهوية البصرية.
- اختيار دروس من محاور الوحدة السادسة.
- رحلة المؤرخ: اكتشف ← اربط ← فسّر ← اختبر ← دافع عن تفسيرك.
- خريطة سببية تفاعلية.
- وضع لماذا؟
- ماذا لو؟ مع تمييز السيناريو الافتراضي.
- تحدي المؤرخ وتقييم أولي.
- تشخيص أولي لأخطاء التفكير.
- لوحة معلم ببيانات تجريبية.
- بنية بيانات قابلة للتوسع وربطها لاحقًا بـ PDF/DOCX ومصادر موثقة.

## ملاحظة مهمة حول محتوى الوحدة السادسة
الـPDF المرفق عبارة عن صفحات مصوّرة. البيانات المدرجة هنا مبنية على المحاور التي أمكن قراءتها من الصفحات، وليست بديلًا عن مراجعة النص الأصلي للكتاب. لا تستخدم التطبيق كمرجع تاريخي نهائي قبل إدخال النصوص/المصادر المدرسية الموثقة.

## ربط الذكاء الاصطناعي لاحقًا
النسخة الحالية تستخدم طبقة تحليل محلية بسيطة حتى تعمل بدون API.
أنشئ لاحقًا:
- app/api/historian/route.ts
- خدمة RAG تعتمد على محتوى الدرس.
- سجل مصادر لكل claim.
- تقييمات منظمة: causality, evidence, context, chronology, multi-causality.
